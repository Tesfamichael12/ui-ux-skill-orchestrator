# Routing scenarios

## Existing button with loading and error states

**Lead:** incumbent component system  
**Specialists:** UI Animation for motion mechanics; Impeccable for state and
accessibility review  
**Excluded:** visual-direction and font/palette research because those axes are
closed.

## Greenfield editorial landing page

**Lead:** Frontend Design  
**Specialists:** UI UX Pro Max for typography and palette evidence; UI
Animation for deliberate motion; Impeccable for responsive production
integration  
**Excluded:** Mies unless a final subtractive pass has a specific purpose.

## Dense enterprise dashboard

**Lead:** Mies or Impeccable, selected from the brief and incumbent product  
**Specialists:** UI UX Pro Max for charts and evidence; UI Animation only for
complex data transitions  
**Validation:** empty, loading, error, partial-data, overflow, keyboard,
localization, and narrow-screen states.

## Figma design-system rules

**Lead:** Figma Design System Rules  
**Precondition:** Figma MCP is connected  
**Behavior when unavailable:** stop the tool-bound workflow, explain the
missing connection, and do not fabricate Figma-derived rules.

## Motion-only refinement

**Lead:** UI Animation  
**Authority:** existing layout, type, and color remain fixed  
**Validation:** rapid interruption, touch, compositor performance, and reduced
motion.
