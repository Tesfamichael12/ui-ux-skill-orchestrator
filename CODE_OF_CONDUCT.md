# Code of Conduct

This project is committed to a respectful, useful, and technically rigorous
community.

Be considerate, critique ideas rather than people, disclose relevant conflicts
of interest, and make room for contributors with different levels of
experience. Harassment, discrimination, threats, doxxing, and deliberately
disruptive behavior are not acceptable.

Maintainers may edit or remove contributions and restrict participation when
necessary to protect the community. Report conduct concerns privately through
the repository owner's GitHub profile. Reports will be handled as
confidentially as practical.
